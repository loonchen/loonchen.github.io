# Long Chen — Academic Homepage

A responsive static academic homepage. Open `index.html` in a browser to preview. No installation or build step is needed. The portrait is stored in `assets/portrait.jpg`; research evidence images are organized under `assets/space/`, `assets/infrastructure/`, and `assets/embodied/`. Click a gallery image to open the full-size original.

## Publish with GitHub Pages

1. Create a repository named `loonchen.github.io` on GitHub.
2. Upload `index.html`, `.nojekyll`, and the `assets/` directory to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select **main / (root)** and save.
4. The site will be available at `https://loonchen.github.io/` after GitHub completes deployment.

For a project repository, the address is `https://loonchen.github.io/REPOSITORY_NAME/`. This page uses no root-relative assets, so either option works.

Official instructions: https://docs.github.com/en/pages/quickstart

## Editing

All content and styles are in `index.html`. Research areas, publications, academic service, and awards have separate semantic sections. Use existing publication rows as a template for additions. Retain accurate paper types and acceptance status when editing.

This directory contains only the public-facing webpage. Original CVs and working documents are not included.
